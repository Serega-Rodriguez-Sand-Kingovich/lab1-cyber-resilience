# Отчёт о безопасности ML-проекта

## 1. Подготовленное окружение

Операционная система: Ubuntu 24.04 LTS.

Основной пользователь разработки: mluser.

Установлены Python, Git, Docker, Docker Compose,
JupyterLab и необходимые ML-библиотеки.

Результаты проверок сохранены в:
reports/evidence/security_checks.txt

## 2. Мини-модель угроз

| Актив | Угроза | Последствие | Контрмера | Статус |
|---|---|---|---|---|
| SSH | Подбор пароля | Несанкционированный доступ | SSH-ключ, запрет root, UFW limit | Реализовано: вход только по ключу подтверждён |
| Датасет | Подмена данных | Некорректное обучение модели | SHA256 и контроль доступа | Реализована проверка SHA256; независимое хранение эталона запланировано |
| Git | Утечка секретов | Компрометация системы | .gitignore и хранение секретов вне Git | .gitignore реализован |
| Python | Уязвимые библиотеки | Компрометация окружения | pip-audit и фиксация версий | Реализовано |
| Сетевые службы | Эксплуатация лишних портов | Увеличение поверхности атаки | UFW, анализ портов, отключение ненужных служб | UFW и анализ реализованы; Avahi отключён |

## 3. Реализованные меры

- Работа от отдельного пользователя mluser.
- Запрет удалённого входа root через SSH.
- Настройка UFW с ограничением SSH-подключений.
- Проверка слушающих сетевых портов.
- Проверка Python-зависимостей через pip-audit.
- Вычисление SHA256 исходного и рабочего датасетов.
- Настройка .gitignore.

## 4. Оставшиеся риски

- Эталонные SHA256 следует хранить независимо от данных.
- Avahi отключён. CUPS оставлен на локальном адресе.
- Аудит зависимостей необходимо выполнять регулярно.
- .gitignore не удаляет секреты из предыдущих коммитов.

## 5. Вывод

Создано минимально защищённое окружение для ML-проекта.
Выполнены проверка зависимостей, анализ сетевой поверхности
и контроль целостности данных.

Реализованные контрмеры уменьшают риски, но не гарантируют
полную защищённость системы.
